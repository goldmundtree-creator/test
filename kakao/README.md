# dNote방 확인 카카오톡 루틴

카카오톡에서 **"dNote방 확인해줘"** 라고 보내면 dNote방에 쌓인 새 메시지를
요약해서 답장해 주는 [메신저봇R](https://violet.develope.kr/) 스크립트입니다.

## 동작 방식

1. 봇이 **dNote** 방에 올라오는 모든 메시지를 기기 내 파일(`sdcard/msgbot/dnote/`)에 기록합니다.
2. 아무 방에서나 `dNote방 확인해줘` 라고 보내면 봇이 답장합니다:
   - 마지막 확인 이후 새 메시지 개수
   - 최근 메시지 최대 10개 (새 메시지는 🆕 표시)
3. 답장을 보낸 시점이 "마지막 확인 시각"으로 갱신됩니다.

## 설치 방법 (안드로이드)

1. Play 스토어 등에서 **메신저봇R** 앱을 설치합니다.
2. 안드로이드 설정에서 메신저봇R에 **알림 접근 권한**을 허용합니다.
3. 카카오톡에서 dNote방의 **알림을 켭니다** (알림이 꺼진 방의 메시지는 봇이 읽을 수 없습니다).
4. 메신저봇R에서 새 봇을 만들고 `dnote_room_routine.js` 내용을 붙여넣은 뒤 컴파일합니다.
5. 봇을 활성화하면 끝입니다.

## 설정 변경

`dnote_room_routine.js` 상단의 상수를 수정하면 됩니다:

| 상수 | 기본값 | 설명 |
|------|--------|------|
| `TARGET_ROOM` | `dNote` | 감시할 카카오톡 방 이름 |
| `TRIGGER` | `dNote방 확인해줘` | 확인 명령어 |
| `MAX_RECENT` | `10` | 답장에 보여줄 최근 메시지 수 |
| `MAX_STORED` | `200` | 파일에 보관할 최대 메시지 수 |

## 제한 사항

- 메신저봇R은 **알림으로 도착한 메시지만** 읽을 수 있습니다. 봇 실행 전의 과거 대화나
  알림이 꺼진 동안의 메시지는 기록되지 않습니다.
- 봇이 설치된 안드로이드 기기가 켜져 있고 카카오톡 알림이 도착해야 동작합니다.
