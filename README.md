# 테트리스 게임 (Tetris Game)

HTML, CSS, JavaScript로 제작된 클래식 테트리스 게임입니다.

## 게임 실행 방법

1. `index.html` 파일을 웹 브라우저로 열기
2. 게임이 자동으로 시작됩니다

## 조작법

- **←/→ (화살표 좌/우)**: 블록 좌우 이동
- **↓ (화살표 아래)**: 블록 빠르게 떨어뜨리기
- **↑ (화살표 위)**: 블록 회전
- **스페이스바**: 블록 한번에 떨어뜨리기
- **P**: 일시정지/재개

## 게임 기능

- ✅ 7가지 클래식 테트리스 블록 (I, J, L, O, S, T, Z)
- ✅ 점수 시스템 및 레벨 진행
- ✅ 라인 클리어 기능
- ✅ 다음 블록 미리보기
- ✅ 반응형 디자인
- ✅ 일시정지 기능
- ✅ 게임 오버 및 재시작

## 점수 계산

- 1줄 클리어: 100점 × 레벨
- 2줄 클리어: 300점 × 레벨
- 3줄 클리어: 500점 × 레벨
- 4줄 클리어: 800점 × 레벨
- 한번에 떨어뜨리기: 칸당 2점

## 레벨 시스템

- 10줄 클리어할 때마다 레벨 상승
- 레벨이 오를수록 블록 낙하 속도 증가

## 기술 스택

- HTML5
- CSS3 (Flexbox, Grid, Gradient)
- JavaScript (Canvas API)

## 특징

- 순수 바닐라 JavaScript로 구현 (외부 라이브러리 없음)
- Canvas API를 활용한 렌더링
- 부드러운 애니메이션
- 직관적인 UI/UX
